# Documentación del frontend

## Consulta obligatoria antes de crear o modificar UI

Leer la [Guía de diseño e interacción](UI_DESIGN_GUIDE.md) antes de añadir paneles, controles, tooltips o nuevos pasos del flujo. Recoge las decisiones adoptadas en el flujo 1 y los componentes que deben reutilizarse.

Complementar la guía con:

1. [Reglas de diseño minimalista](../desing.md): organización del CSS, microinteracciones y accesibilidad.
2. [Arquitectura del frontend](FRONTEND_ARCHITECTURE.md): responsabilidades y ubicación de archivos.
3. [Flujo del prototipo](PROTOTYPE_UI_FLOW.md): contexto funcional y aparición progresiva de herramientas. Sus plegables y etiquetas históricas no sustituyen las decisiones de la guía actual.

## Recursos del flujo 1

- [Decisiones de diseño e interacción](UI_DESIGN_GUIDE.md)
- [SVG de las opciones principales](Flujo%201/svg.md)

Cuando se acuerde un cambio de interacción o apariencia, actualizar la guía junto con la implementación para que las siguientes pantallas mantengan el mismo criterio.
